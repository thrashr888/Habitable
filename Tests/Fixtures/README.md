# Manual Terraform workspaces

`Playground` is the source template for the richer, credential-free Habitable test folder. Open a prepared copy rather than this template: the data-source example needs the local state generated by setup.

From the Habitable checkout, run:

```sh
scripts/create-playground.sh "/private/tmp/Habitable Playground"
```

The script uses Terraform on PATH, or the executable specified by `HABITABLE_TEST_TERRAFORM` / `HABITABLE_TERRAFORM_PATH`. It requires Terraform 1.4 or newer, applies only local built-in metadata resources to create a baseline, and leaves the mixed-change review plan unapplied. It refuses an existing destination so test edits are preserved; use a different folder name for a fresh copy.

The generated folder's README describes the main workspace and its Missing Inputs, Validation Errors and Readme Only companions. State, cached modules, logs and saved plans stay in that generated folder and are excluded from its optional Git history. Setup does not create Git history automatically.

`RemoteOutputsOnly` is a separate existing HCP Terraform fixture and is not used by the local playground setup.
